An AI-powered Video Resume Generator!

This project takes a traditional PDF resume, extracts the content, converts it into natural-sounding speech with a male AI voice, and overlays it with creative VFX-inspired visuals – blending images, text, and audio to produce a professional, cinematic video resume.

It combines Python, PyMuPDF, pdfplumber, gTTS/pyttsx3, and OpenCV to handle everything from text extraction to video rendering – without relying on MoviePy. The result is a beautiful, automated pipeline that transforms static resumes into engaging video storytelling tools.
